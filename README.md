# Face Rating Bot — Telegram-бот «дайвинчик с ИИ»

Бот, где участники заполняют анкету (имя, группа, курс, **ровно 3 фото**, свой «тип»), ИИ ставит
рейтинг лица **от 0 до 5** с характеристиками, а другие участники соглашаются или спорят и могут
оставить комментарий. Есть батлы 1 на 1 с рейтингом Elo.

> ⚠️ Это развлечение. Оценка — эвристика по пропорциям и симметрии лица, а не научная оценка
> внешности и тем более человека.

## Возможности

- 📝 Анкета: имя, группа, курс, самооценка (кнопки), 3 фото (не меньше и не больше).
- 🤖 AI-анализ каждого фото (MediaPipe Face Mesh, 468 точек лица): симметрия, кантальный наклон глаз,
  трети лица, fWHR, челюсть/скулы, расстояние между глазами, рот/нос. Итог — среднее по 3 фото, 0–5.
- 🏷 Тип по шкале с картинки: Sub 3 → Sub 5 → ITN → MTN → HTN → Chadlite → Chad → True Adam.
- 🔥 Оценивание: «Пользователь думает, что он: **Chad**». Другой участник может
  **согласиться** или выбрать **свой тип**, затем оставить комментарий.
- ⚔️ Батлы: две анкеты, выбираешь лучшую; рейтинг Elo и топ.
- 👤 «Моя анкета»: твои характеристики, мнения других и комментарии (анонимно).
- 🗑 Удаление анкеты и всех данных одной кнопкой; при регистрации подтверждается 18+ и согласие на показ фото.

## Про шаблон `.ai` из ТЗ

Файл `BH_Face_99x65_cs2.ai` — это графический шаблон интерфейса для Adobe Illustrator, он не умеет
распознавать лица. Вместо него используется **MediaPipe Face Mesh** (бесплатный, работает на CPU,
ставится через `pip`). Критерии в духе looksmax (симметрия, canthal tilt, трети, fWHR, jaw-to-cheek)
реализованы в `face.py`; пороги и веса там же — их легко подкрутить.

| Файл | Назначение |

## Токен

1. Создай бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. Один из вариантов (по приоритету):
   - переменная окружения `BOT_TOKEN` (**рекомендуется на Railway**);
   - строка `BOT_TOKEN = ""` в начале `bot.py`;
   - ничего не указывать: при первом локальном запуске бот спросит токен в консоли и сохранит в `.token`.

> 🔒 Если вставляешь токен прямо в `bot.py`, репозиторий на GitHub должен быть **приватным**.
> Публичный токен надо сразу перевыпустить в BotFather (`/revoke`).

## Локальный запуск

Нужен Python 3.9–3.11 (под mediapipe 0.10.14).

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

## Деплой на Railway

1. Создай **приватный** репозиторий на GitHub и загрузи туда все файлы из архива.
2. На [railway.app](https://railway.app): **New Project → Deploy from GitHub repo** → выбери репозиторий.
   Railway найдёт `Dockerfile` и соберёт образ сам.
3. Открой сервис → **Variables** → добавь `BOT_TOKEN` = твой токен (если не вписал его в `bot.py`).
4. Чтобы база не пропадала при перезапуске: **Volumes → New Volume**, mount path `/data`,
   и добавь переменную `DB_PATH=/data/bot.db`.
5. Deploy. В логах должно появиться `Бот запущен: @твой_бот`. Порт и домен не нужны — бот работает через polling.

## Настройка

- Пороги типов: `THRESH` в `bot.py`.
- Веса метрик и «идеальные» значения: `WEIGHTS` и функция `analyze` в `face.py`.
- Список типов: `TYPES` в `bot.py`.

## Ограничения

- Алгоритм предполагает фото анфас при нормальном свете: наклон головы, очки, фильтры и маски искажают результат.
- Хранятся Telegram `file_id` фото, а не сами файлы.
- Состояние диалогов хранится в памяти — при перезапуске незаконченная регистрация сбрасывается (готовые анкеты остаются в БД).
